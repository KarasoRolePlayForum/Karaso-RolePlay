KARASO ROLEPLAY - CLEAN STAFF WEBSITE

Homepage: index.html
- Forum, shop, and launcher sections and links have been removed from the homepage.

- Remaining public staff resources: staff commands and staff directory.

Staff pages:

Deployment: upload the CONTENTS of this ZIP to the root of the GitHub Pages repository, replacing old files.

Database: this package does not execute or modify Supabase SQL. It expects the previously configured Supabase project and required staff tables/RPCs.
